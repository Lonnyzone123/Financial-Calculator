## 1. The owner's decision

ChatGPT's R44-01 said the R43 part 2 proof's "paths change; the published result may move" does not predict a published
case, field, direction or size, as A-01 asks. It offered two resolutions: a second stage that predicts published movement,
or an explicit owner exception for stochastic forecasts.

The owner chose the exception. **Amendment A-11** (`S5AA_TASK_CHECKLIST.md`) sets out what a prediction for a Monte Carlo
plan must contain, and how it is judged:
- **It must name:** the plan, with the rule it is exposed to; the exposed paths, by a necessary-condition test run on every
  path; and a published result that "may move".
- **It is not a miss** when a named plan's published result does not move.
- **It is a miss** when an unnamed plan's published result moves, or when a changed path was not named.
- **Every other plan keeps A-01 as written.**

The checklist that applies it is `S5AA_R44_1_PREDICTION_CHECKLIST_20261001.md` (C4 and C8 revised).

## 3. Path 390: why R44's corrected scan missed it, and what changes

R44's corrected scan added a second stage after the exposure test.
- **What the second stage did:** it rebuilt each exposed path's accounts from the path's published row fields (each class's
  balance at the row's close, shared equally among its accounts, and a return ratio taken from row totals). It then kept the
  path only if the engine's `smartWithdrawalOrder()` returned a different class order under the two tables.
- **What went wrong on path 390** (`path390_check_d11017f_b131aeb.txt`):
  - the guard flips at row 59 (age 87), the first row whose figures change;
  - under the rebuilt state, the order is `preTax, taxable, roth, hsa` under both tables, so the second stage dropped the
    path;
  - `irmaaGuard` has one reader (`smartWithdrawalOrder()`), so the engine's real order did change on that path.
- **The cause:** the rebuilt state is not the engine's state at the moment of the draw.
- **The same approximation** kept four band paths that did not change (19, 71, 457, 467).

**The revised C4:** a stage that approximates a path's state may rank exposed paths, but must not remove one. The exposure
test alone, a necessary condition, named every changed path in both plans.
